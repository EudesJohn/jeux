## Français

### 1. Ce que ce jeu ne fait pas

Abomey Warriors est un jeu **hors ligne**. Il ne demande **aucun compte**, ne
contient **aucune publicité**, **aucun outil de mesure d'audience** (analytics),
**aucun module de suivi** ni **aucun service tiers** de collecte.

Johnson Studio **ne collecte, ne transmet et ne vend aucune donnée personnelle**.
Aucun nom, e-mail, numéro, contact, photo, position ni identifiant publicitaire
n'est lu ou envoyé.

### 2. Données enregistrées sur votre appareil

Le jeu enregistre uniquement, **dans son propre dossier sur le téléphone** :

- la progression (niveaux terminés, étoiles, cauris, améliorations) ;
- les réglages (langue, volumes, difficulté, taille des boutons, qualité) ;
- le record de Survie et la série du Défi du jour.

Ces fichiers ne quittent jamais l'appareil. Ils sont supprimés quand vous
désinstallez le jeu ou effacez ses données depuis Android. Aucune sauvegarde
n'est envoyée sur un serveur.

### 3. Coopération en réseau local

Le mode coopératif à deux joueuses utilise le **réseau Wi-Fi local** : l'hôte
diffuse sa présence sur le réseau pour que l'autre téléphone le trouve, puis les
deux appareils échangent directement leur position et l'état de la partie.

- Aucun serveur de Johnson Studio n'intervient.
- Aucune donnée n'est conservée après la partie.
- Seules les informations nécessaires au jeu circulent : position des
  personnages, dégâts, vagues, objectifs et identifiant de la partie.
- La permission `INTERNET` est déclarée parce que le moteur Godot en a besoin
  pour ouvrir une connexion locale ; elle n'est utilisée que pour cette
  connexion entre les deux téléphones.

### 4. Autorisations demandées

| Autorisation | Pourquoi |
|---|---|
| `VIBRATE` | retour haptique pendant les combats (désactivable dans les réglages) |
| `INTERNET` | connexion locale du mode coop (voir § 3) |
| `ACCESS_NETWORK_STATE` | savoir si le Wi-Fi est disponible avant de proposer le coop |
| `ACCESS_WIFI_STATE` | afficher l'adresse de l'hôte |
| `CHANGE_WIFI_MULTICAST_STATE` | diffusion locale qui permet à l'invitée de trouver la partie |

Aucune autre autorisation n'est demandée : ni localisation, ni contacts, ni
photos, ni micro, ni caméra, ni stockage externe.

### 5. Enfants

Le jeu ne collecte aucune donnée, n'affiche aucune publicité et ne propose
aucun achat intégré. Il peut donc être utilisé par des enfants sans collecte
d'informations les concernant.

### 6. Vos droits

Comme aucune donnée personnelle n'est collectée, il n'y a rien à consulter, à
corriger ou à porter ailleurs. Pour effacer les données locales : désinstaller
le jeu, ou *Paramètres Android → Applications → Abomey Warriors → Stockage →
Effacer les données*.

Pour toute question : **eudesjohn650@mail.com** (réponse sous 30 jours).

### 7. Modifications

Toute évolution du jeu qui ajouterait une collecte de données serait accompagnée
d'une nouvelle version de cette politique, publiée à la même adresse, avant la
mise à jour concernée.

## English

### 1. What this game does not do

Abomey Warriors is an **offline** game. It requires **no account**, contains
**no advertising**, **no analytics** and **no third-party tracking SDK**.
Johnson Studio **does not collect, transmit or sell any personal data**.

### 2. Data stored on your device

The game only writes, inside its own app storage: progress (levels, stars,
currency, upgrades), settings (language, volume, difficulty, button size,
quality), the Survival record and the Daily Challenge streak. These files never
leave the device and are removed when you uninstall the game or clear its data.
No server backup exists.

### 3. Local-network co-op

Two-player co-op uses the **local Wi-Fi network**: the host announces itself on
the network, the other phone connects directly, and the two devices exchange the
data needed to play (positions, damage, waves, objectives, session id). No
Johnson Studio server is involved and nothing is kept after the session. The
`INTERNET` permission is declared because Godot needs it to open that local
connection; it is used for nothing else.

### 4. Permissions

`VIBRATE` (haptic feedback, can be disabled in settings) · `INTERNET` (local
co-op only) · `ACCESS_NETWORK_STATE` and `ACCESS_WIFI_STATE` (detect Wi-Fi and
display the host address) · `CHANGE_WIFI_MULTICAST_STATE` (local discovery).
No location, contacts, photos, microphone, camera or external storage access is
requested.

### 5. Children

No data collection, no ads, no in-app purchases: the game is safe for children.

### 6. Your rights

Since no personal data is collected, there is nothing to access, correct or
transfer. To erase local data: uninstall the game, or *Android Settings → Apps →
Abomey Warriors → Storage → Clear data*. Questions:
**eudesjohn650@mail.com** (answered within 30 days).

### 7. Changes

Any future feature that would collect data would ship with a new version of this
policy, published at the same address, before the related update.
